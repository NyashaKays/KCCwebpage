# Kokomo Cottage Community

Single-page React + Vite website. Run `npm install`, `npm run dev`, and `npm run build`.

## DreamHost deployment
Upload the contents of `dist/` to the domain's web directory. No Node.js server is needed in production. All navigation is within the single page, so no SPA rewrite rule is required. Build on your computer or GitHub Actions.

Contact links open the visitor's email or phone application. There is no submission backend or database. Update contact details and content in `src/main.jsx`; colors and responsive layout are in `src/style.css`.

## Content
Based on the supplied KCC press release and flyer and Fortune Architecture's KCC blog articles. Color values #2e6446 and #bed8c9 match Fortune Architecture's published Elementor palette. Images are retained locally. Architectural visuals and community plans are labeled as illustrative/proposed. Current price, inventory, financing, HOA fees, and completion dates must be confirmed with Fortune Companies. No historical price is advertised as a current offer.
